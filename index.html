About My-OS

My-OS is a hybrid concept:

  • A Linux-based operating-system roadmap (docs + compatibility tooling).
  • A browser-delivered desktop shell for instant access on GitHub Pages.
  • A Scramjet-focused browser app slot for privacy-first browsing workflows.
